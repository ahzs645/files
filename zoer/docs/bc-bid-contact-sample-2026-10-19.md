# BC Bid contact sample — October 19, 2026

## Scope and evidence

This appendix records **20 purposively selected public notices** from a live review that visited all **49 pages** of the BC Bid **Open** listing. Each row links to the public opportunity. Source evidence is the recorded live audit exported at **2026-10-19T16:05:40.449Z**. Opportunity IDs and process IDs are both retained where they differ. Names, email spelling and capitalization follow the published source.

The 20 details are a sample, not a census of all opportunity contacts. The installed Zoer runtime and user catalog were unavailable for comparison. These observations establish what the public source displayed; they do not establish whether those records are correct in the installed Zoer catalog.

## Interpretation and parser checks

- **PHSA 19923:** the source publishes both the buyer email, bernie.chauvin@phsa.ca, and the platform support email, Support@GoBonfire.com. Their roles must remain distinct. The support address is not the buyer contact.
- **Royal BC Museum process 235043:** Lorelei Fitzpatrick and tduce@royalbcmuseum.bc.ca are the pair published by the source. This appendix records that pair without inferring an error from the email local part.
- **TA1490:** an Email Address question in a nested Responses section asks for an applicant’s response. It is separate from the buyer’s published office address.
- **Multi-use lists:** all four sampled Qualified Suppliers panes explicitly withheld their sensitive/confidential lists. That observed source message must not be treated as a scraper failure or as evidence that zero suppliers qualified.
- **Actual RDFFG layout check:** the live source-derived contact-layout excerpt for [process 235069](https://bcbid.gov.bc.ca/page.aspx/en/bpm/process_manage_extranet/235069) produced the same correct Bonnie / Seitz / bseitz@rdffg.bc.ca fields in both the original and patched shared parser. The result was unchanged in an explicitly simulated sanitization that removed only scripts, styles and hidden inputs. Scripts were never executed. This current source layout did not reproduce the authored nested-layout defect case.
- **Historical source-derived regression evidence:** a separately saved public excerpt for [BC Transit process 231457](https://github.com/ahzs645/files/blob/6fbf90284cf7b61d538ba27078bed29854fbc3e2/tests/fixtures/detail/bc-transit-231457.html), supplied September 27, displays procurement@bctransit.com but links to mailto:procurement@bctranist.com. This actual source discrepancy supports prioritizing the displayed address. It is outside the 20-notice live sample. The nested-label, hidden-value, multiple-address and contact-mapping failure cases in the new tests are authored regressions; they do not measure error prevalence in these 20 live notices.
